# Sistema-Nivel-Reservatorio-esp32
Sistema IoT de monitoramento de reservatório industrial com ESP32, sensor ultrassônico de nível e sensor NTC de temperatura. Dados transmitidos via MQTT para o HiveMQ, processados no Node-RED com dashboard em tempo real, alertas automáticos e persistência em MySQL no Clever Cloud. Integração com API OpenWeather para monitoramento climático externo.
